# Versions

## 1.3.0

* New name: Ghost.

## 1.2.24

* During hero selection you see allies' picks that the game hides until strategy time: Ghost reads them from the top bar portraits.

## 1.2.23

* Lighter on FPS: the window draws 3–4 times faster, with fewer garbage collection pauses.

## 1.2.22

* Portraits in the hero grid are no longer stretched.
* The draft mode follows the game: Captains Mode in turns, every other mode as a free pick.

## 1.2.21

* Selling and backpack: a freshly bought item goes to the backpack instead of being sold; a build item in the backpack moves into a main slot; late items are not bought without room.

## 1.2.20

* The hero grid fits the window completely.

## 1.2.19

* New window layout: the arena with the win chance in the middle, the build with a hero banner, settings in two columns.
* Updates always install by themselves.

## 1.2.18

* New palette and logo.
* Updates from GitHub between matches.
* Fixed item selling in auto buy.
* Items can be hidden from builds.
* The build rebuilds when you buy off the plan.
* Skills and talents fit the match.
* Suggest a hero to allies without the chat.
