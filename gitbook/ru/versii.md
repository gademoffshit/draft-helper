# Версии

## 1.3.0

* Новое имя: Ghost.

## 1.2.24

* На стадии выбора видны пики союзников, которые игра прячет до стратегии: Ghost берёт их по портретам в верхней панели.

## 1.2.23

* Меньше нагрузки на FPS: окно рисуется в 3–4 раза быстрее, пауз на сборку мусора меньше.

## 1.2.22

* Портреты в сетке героев больше не растягиваются.
* Режим драфта определяется по игре: Captains Mode по очереди, остальные режимы свободно.

## 1.2.21

* Продажа и рюкзак: свежекупленный предмет уходит в рюкзак, а не продаётся; нужный предмет из рюкзака встаёт в основной слот; поздние предметы не покупаются, если для них нет места.

## 1.2.20

* Сетка героев целиком помещается в окно.

## 1.2.19

* Новая компоновка окна: арена с шансом по центру, сборка с баннером героя, настройки в две колонки.
* Обновление ставится само всегда.

## 1.2.18

* Новая палитра и логотип.
* Обновление с GitHub между матчами.
* Исправлена продажа предметов автозакупкой.
* Предметы можно скрыть из сборок.
* Сборка перестраивается, если купил не по плану.
* Навыки и таланты подбираются под матч.
* Предложение героя союзникам без чата.
